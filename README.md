# OK Automation website

One-page static site for OK Automation (simple automations for small businesses).

- Everything is in `index.html`, with no build step. Preview it with `open index.html`.
- **Contact email:** set `CONTACT_EMAIL` near the top of the `<script>` block.
- The "Try it" demo runs entirely in the browser and sends nothing.
- Hosted on GitHub Pages from the `main` branch root. Push to update the live site.
